# 🎵 CeziRooms v5.5 - Music, AI & Social Experience

CeziRooms adalah platform hiburan berbasis web yang menggabungkan fitur pencarian musik real-time, asisten cerdas **Omni-AI**, dan sistem pertemanan sosial. Dirancang dengan **iOS Design System** untuk memberikan pengalaman aplikasi premium langsung dari browser.

## 🚀 Fitur Utama v5.5

* **Permanent Account:** Login menggunakan nomor HP. Akun dan data Anda tersimpan permanen di perangkat (LocalStorage).
* **Music Discovery:** Cari dan putar jutaan lagu secara gratis melalui integrasi **iTunes API**.
* **Omni-AI Helper:** Asisten menu-based yang siap membantu navigasi web, info dev, dan laporan masalah.
* **Social System:** Tambah teman secara real-time melalui Username atau Nomor HP.
* **Dev Dashboard:** Dashboard khusus pengembang untuk memantau aktivitas user dan laporan bug secara langsung.
* **PWA Ready:** Bisa diinstal di layar utama HP (Add to Home Screen) tanpa iklan.

## ⚙️ Cara Instalasi (Local)

1.  Clone atau Download repository ini.

3.  Buka `index.html` di browser (Disarankan Chrome atau Safari Mobile).
4.  Lakukan login pertama kali untuk membuat akun permanen.
